# RAIM 예약현황 일괄 출력 (크롬 확장)

서울시 공공예약 관리자 화면(예약관리 › 예약현황관리)에서 고른 서비스의 예약현황 엑셀을 **서비스당 1건씩** 받아 RAIM Manager 출석부 탭으로 바로 넘깁니다.
회차마다 팝업을 열고 엑셀을 출력하던 과정이 "서비스 체크 → 회차 확인 → 보내기" 세 번의 클릭으로 줄어듭니다.

## 설치 (직원)

**지금(웹스토어 게시 전)**: RAIM Manager의 설명서 › 8. 크롬 확장에서 `raim-extension.zip`을 내려받아 압축해제 설치합니다.
단계별 안내는 설명서에 있습니다. 이 zip은 `npm run build`가 매번 `npm run ext:pack:site`로 `extension/`에서 새로 만들어
`public/downloads/`에 두므로(저장소에는 넣지 않음), 확장을 고친 뒤 main에 배포하면 내려받기 파일도 함께 바뀝니다.
새 버전을 낼 때는 manifest의 `version`을 올려야 직원이 설명서와 출석부 화면의 버전을 비교해 업데이트할 수 있습니다.

**웹스토어 게시 후**: 크롬 웹스토어에 **비공개 링크(Unlisted)** 로 올려 두면, 직원은 개발자 모드 없이 설치합니다.

1. 공유받은 웹스토어 링크를 크롬에서 엽니다. (RAIM Manager 출석부 화면의 "크롬 웹스토어에서 설치하기" 링크도 같은 곳입니다)
2. **Chrome에 추가** → **확장 프로그램 추가**
3. 끝. 새 버전은 크롬이 알아서 업데이트합니다.

비공개 링크는 검색에 나오지 않지만, 링크를 아는 사람은 누구나 설치할 수 있으니 직원끼리만 공유하세요.
(설치해도 공공예약 관리자 로그인이 없으면 아무 것도 할 수 없습니다.)

기관 PC에서 웹스토어 설치가 막혀 있으면, 전산 담당자에게 확장 ID를 허용 목록에 넣거나
정책(`ExtensionInstallForcelist`)으로 일괄 설치해 달라고 요청하면 됩니다.

## 웹스토어 게시 (배포 담당자)

1. 크롬 웹스토어 개발자 계정 등록 (1회 등록비, 개발자 이메일은 나중에 못 바꿉니다)
   - 담당자가 바뀔 것을 생각해 개인 계정보다 **과학관 공용 구글 계정**으로 등록하는 것을 권장합니다.
     개인 계정으로 올렸다면 인수인계 때 지원 양식으로 항목을 새 계정에 이전할 수 있습니다.
2. `npm run ext:pack` → `release/raim-extension-<버전>-store.zip`
   (개발용 주소가 남아 있거나, console 출력·data: URL·downloads 권한이 있으면 묶지 않고 멈춥니다)
3. 대시보드에서 새 항목 → zip 업로드 → `store/STORE_LISTING.md`의 내용과 이미지로 등록정보·개인정보 항목을 채우고
   공개 범위를 **비공개 링크**로 정해 심사 제출 (심사는 며칠에서 몇 주 걸릴 수 있습니다)
4. 게시 후 할 일은 `store/STORE_LISTING.md` 맨 아래를 따릅니다 (manifest `key` 교체, RAIM에 스토어 ID·주소 등록).
5. 새 버전: manifest의 `version`을 올리고 2~3을 반복합니다.

## 설치 (개발자, 압축해제)

1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택 (폴더를 옮기거나 지우면 확장이 꺼집니다)
3. 확장 ID가 `ohjbofjcjnkidgidaclhnppmcncnfbjf`인지 확인합니다.
   manifest의 `key`로 고정돼 있고, RAIM Manager(`src/lib/extensionBridge.ts`의 `RAIM_EXTENSION_IDS`)에 등록된 ID하고만 통신합니다.

## 사용법

1. 공공예약 관리자에 로그인 → 예약관리 › 예약현황관리 (분류를 교육강좌로 걸러 두면 편합니다)
2. 서비스 이름 왼쪽 체크박스로 서비스를 고릅니다. (한 페이지 안에서만 선택이 유지되니 "100개" 보기를 권장합니다)
3. 오른쪽 아래 **RAIM 출석부 보내기** 패널에서
   - 이용일: 서비스 이용기간 전체, 또는 기간 지정(오늘 / 이번 주말 / 다음 주말)
   - 다운로드 사유: 기본 **출석부 작성**
4. **1. 회차 확인** → 서비스별 회차 수를 미리 봅니다. (개인정보 없는 회차 목록만 조회)
5. **2. RAIM으로 보내기** → RAIM Manager 출석부 탭이 열리고 회차별로 자동 분리됩니다.
   패널에 "출석부 회차 N개" 결과가 돌아오며, 사이트 회차 수보다 적으면 ⚠로 알려 줍니다.
   - RAIM 탭에서 로그인·PIN·프로그램 선택이 남아 있으면, 마치고 출석부 탭을 열 때 5분 안에는 자동으로 들어갑니다.
6. RAIM에 바로 넘길 수 없을 때는 **ZIP으로 저장** → 받은 ZIP을 출석부 탭에 끌어다 놓으면 됩니다.

툴바의 확장 아이콘을 누르면 기본 사유와 요청 간격을 바꿀 수 있습니다.

## 보안·개인정보

| 항목 | 내용 |
| --- | --- |
| 사이트 요청 | `yeyak/api.js`의 2개 주소만: 회차 목록(개인정보 없음), 예약현황 엑셀 출력. 추첨·문자·수정·취소 요청은 코드에 없습니다. |
| 다운로드 기록 | 관리자 화면의 엑셀 출력 버튼과 같은 요청이라, 서비스마다 다운로드 사유가 사이트에 그대로 기록됩니다. 명단 JSON API는 쓰지 않습니다. |
| 외부 전송 | 없음. 확장은 공공예약 사이트 외에는 어디에도 요청하지 않습니다. RAIM Manager도 받은 파일을 브라우저 안에서만 처리합니다. |
| RAIM으로 전달 | `externally_connectable` 1:1 채널. `https://raim.kimjihoon.me`에서, 그중에서도 **확장이 직접 연 탭의 출석부 화면**만 가져갈 수 있습니다. `window.postMessage`로 창 전체에 뿌리지 않습니다. 보낸 묶음마다 ID를 붙여 결과가 다른 작업과 섞이지 않습니다. |
| 보관 | `chrome.storage.session`(메모리)에만, 한 번 넘기면 즉시 삭제, 5분이 지나면 알람으로 삭제, 브라우저를 닫으면 사라집니다. 디스크(`storage.local`)에는 설정만 저장합니다. |
| 파일 저장 | ZIP 하나를 blob으로 저장합니다. `data:` URL을 쓰지 않아 다운로드 기록에 내용이 남지 않고, `downloads` 권한도 없습니다. 저장 링크는 닫힌 섀도 루트 안에서만 잠깐 만들어 사이트 스크립트가 볼 수 없습니다. |
| 권한 | `storage`, `alarms`(만료 삭제), raim.kimjihoon.me 탭 찾기뿐입니다. 공공예약 화면에는 콘텐츠 스크립트로만 붙습니다. |
| 로그 | `console`에 예약자 정보를 찍지 않습니다. RAIM이 돌려주는 결과는 파일 식별자와 회차 수뿐입니다. |

남는 위험과 대비:

- 확장은 이미 로그인된 브라우저를 그대로 씁니다. 공용 PC라면 사용 후 공공예약에서 로그아웃하세요.
- "모든 사이트 읽기" 권한을 가진 다른 확장은 이 확장과 상관없이 관리자 화면과 RAIM 화면 자체를 읽을 수 있습니다. 업무용 크롬에는 꼭 필요한 확장만 두세요.
- RAIM Manager는 GitHub의 main 브랜치가 그대로 배포됩니다. GitHub 계정에 2단계 인증을 켜고, 저장소 설정에서 사용자 도메인(raim.kimjihoon.me)을 인증해 두세요.
- RAIM Manager가 쓰는 `xlsx@0.18.5`에는 조작된 엑셀로 일으킬 수 있는 알려진 취약점(CVE-2023-30533, CVE-2024-22363)이 있습니다. 파일 출처가 공공예약 공식 출력이라 위험은 낮지만, SheetJS 0.20.x로 올리는 것을 권장합니다.

## 사이트가 바뀌었을 때

- 요청 주소·파라미터: `yeyak/api.js` (`ENDPOINTS`, `fetchServiceExcel`)
- 목록 화면 구조(체크박스 위치, 이용기간 칸): `yeyak/list.js`의 `readServices`
- 엑셀 열 이름이 바뀌면 RAIM Manager의 `src/lib/reservationUtils.ts`를 고칩니다.

## 로컬 개발 (localhost:3000)

배포본은 `https://raim.kimjihoon.me`하고만 통신합니다. 로컬에서 시험할 때만 아래 세 곳의 주소를 `http://localhost:3000`으로 잠시 바꾸고, 끝나면 되돌리세요.

- `manifest.json`의 `host_permissions`, `externally_connectable.matches`
- `shared.js`의 `RAIM_ORIGIN`
