RAIM 예약현황 일괄 출력 개인정보처리방침

크롬 확장 프로그램 · 시행일 2026-10-17

1. 이 확장이 하는 일

서울시 공공예약 관리자 화면(예약관리 › 예약현황관리)에서 관리자가 고른 서비스의 예약현황 엑셀을 사이트의 엑셀 출력 기능과 같은 방식으로 받아, 같은 브라우저에 열린 RAIM Manager 출석부 화면(https://raim.kimjihoon.me)으로 넘깁니다. 출석부·문자발송 명단은 RAIM Manager가 브라우저 안에서 만듭니다.

2. 다루는 정보

예약현황 엑셀신청자 이름, 연락처, 회차, 이용일, 신청 상태 등 공공예약 사이트가 출력하는 항목. 관리자가 이미 볼 권한이 있는 정보만 받습니다.
설정기본 다운로드 사유, 요청 간격. 개인정보가 아닙니다.

3. 저장과 전송

  • 외부 전송 없음. 개발자나 제3자의 서버로 어떤 정보도 보내지 않습니다. 확장이 요청하는 곳은 공공예약 사이트(관리자 본인의 로그인 세션)뿐입니다.
  • 브라우저 안에서만 전달. 받은 엑셀은 브라우저 메모리(chrome.storage.session)에만 잠깐 두었다가, 확장이 연 RAIM Manager 출석부 화면에 1:1 채널로 한 번 넘기고 즉시 지웁니다. 5분 안에 가져가지 않으면 자동으로 지우며, 브라우저를 닫아도 사라집니다.
  • 디스크 저장 없음. 확장의 영구 저장소에는 설정만 저장합니다. 관리자가 "ZIP으로 저장"을 누른 경우에만 그 PC의 다운로드 폴더에 파일이 저장됩니다.
  • 기록 남기지 않음. 분석 도구, 광고, 로그 수집을 쓰지 않습니다.

4. 사이트 기록

엑셀을 받을 때마다 공공예약 사이트에 관리자가 고른 다운로드 사유(기본 "출석부 작성")가 사이트의 엑셀 출력과 똑같이 기록됩니다.

Privacy Policy (English summary)

"RAIM 예약현황 일괄 출력" lets a logged-in administrator of the Seoul public reservation admin site export reservation spreadsheets for selected services (the same export the site provides) and hand them to the RAIM Manager attendance page (https://raim.kimjihoon.me) open in the same browser.

  • No data is sent to the developer or any third party. The only network requests go to the reservation admin site using the administrator's own session.
  • Exported files are kept only in browser memory (chrome.storage.session), handed once to the RAIM Manager tab opened by the extension, and deleted immediately (or after 5 minutes).
  • Only settings (default download reason, request interval) are stored persistently. Files are written to disk only if the administrator clicks "ZIP으로 저장".
  • No analytics, advertising, or logging. Data is not sold, transferred, or used for unrelated purposes.
